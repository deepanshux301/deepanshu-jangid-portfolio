# Deepanshu Jangid - Modern Developer Portfolio

A modern, responsive, high-performance personal portfolio website built with pure semantic HTML5, CSS3, and Vanilla JavaScript. Engineered for a B.Tech Artificial Intelligence & Machine Learning student at JECRC University with clean typography, dark theme aesthetics, subtle purple/cyan accents, and zero external framework bloat.

---

## 🌟 Key Features

- **Performance-First Architecture**: Built purely with HTML5, CSS3, and Vanilla JavaScript. Fast load times and zero dependency overhead.
- **Modern Dark Theme & Aesthetics**: Ambient glow accents, glassmorphic cards (`backdrop-filter`), subtle gradients (`#a855f7` to `#06b6d4`), and clean macOS-style terminal preview in the hero section.
- **Fluid Responsiveness**: Adapts smoothly to mobile devices (<480px, <768px), tablets, and high-resolution desktop viewports. Includes a mobile slide-out navigation drawer with an animated hamburger icon.
- **Scroll-Spy & Sticky Header**: Sticky top navigation bar with auto-updating active link indicator as you scroll through sections.
- **Interactive Contact Features**:
  - One-click **"Copy Email"** buttons with floating toast alerts.
  - Interactive contact form with real-time validation and mail client launcher.
- **Realistic Student Content**: Structured around genuine AI/ML and computer engineering coursework, skills (Java, C/C++, JS, HTML, CSS, Git, DSA, OOP, DBMS), realistic projects, and milestone categories with clear placeholders.
- **Accessibility & Standards**: Semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), ARIA attributes, visible focus states, and reduced-motion support.

## 🚀 How to Run Locally

You can open the website directly or serve it via any local web server:

### Option 1: Direct File Open
Double click `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Using Python (Recommended)
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your web browser.

### Option 3: Using VS Code Live Server
Open the portfolio folder in Visual Studio Code, right-click `index.html`, and select **Open with Live Server**.

## ✏️ Customization & Placeholders Checklist

All missing personal details are marked with clear bracketed placeholders in [index.html](file:///c:/Users/Deepanshu%20Jangid/OneDrive/Desktop/portfolio/index.html). Here is what you can customize:

1. **Contact Details & Socials**:
   - `[your-github-username]`: Replace with your actual GitHub username.
   - `[your-linkedin-profile]`: Replace with your LinkedIn vanity slug.
   - `[deepanshu.jangid.dev@example.com]`: Replace with your actual contact email address.
   - `[City, State, India]`: Update with your current city/location.

2. **Education Details**:
   - `[2022 – 2026 / Present]`: Adjust graduation batch years.
   - `[CGPA: e.g. 8.x / 10 or Aggregate %]`: Update with your score.
   - `[Your School Name • CBSE / State Board]`: Update high school details.

3. **Project Repositories**:
   - Update project links (`https://github.com/[your-github-username]/[repo-name]`) to point to your live repos or deployment links.

4. **Certifications & Milestones**:
   - `[Milestone: e.g. 150+ Problems Solved in Java/C++]`: Enter your actual coding milestone.
   - `[e.g. NPTEL / HackerRank Problem Solving / Coursera]`: Enter your verified certification names.
   - `#[certificate-verify-url]`: Link to your credential verification URLs.
